PDF 复制助手

复制之后，顺手读懂。

在扩展 PDF 阅读模式中，复制原文时显示译文；取消选中即可收起。

只将本次复制的文字发送给你选择的服务，不上传 PDF 文件。复制到剪贴板的仍是换行转空格后的原文。

自动识别原文语言。需要能访问 Google；此免密钥接口不是 Google Cloud 的正式 API，可能限流或不可用。

预设只决定参数格式。Base URL 和模型名始终可编辑，切换预设会保留已填写的地址和模型名。

GPT 参数

较低推理强度通常更快。处理档位影响请求调度，不等同于思考强度；Fast / Priority 可能使用不同计费，需服务商支持。详细程度不改变“只返回译文”的要求。

OpenAI 官方参数说明 ↗

DeepSeek 参数

适用于当前 DeepSeek 模型。关闭思考后不发送推理强度；选择明确的强度会启用思考。没有单独的“速度”参数，优先速度时可关闭思考或选择 low。

DeepSeek 官方参数说明 ↗

Token 上限包含推理开销，过低可能没有完整译文。高强度思考时可适当延长等待上限。实际参数支持范围以所填模型及中转服务为准。

API_KEY 以 AES-GCM 加密保存。口令不保存，忘记后需重新填写密钥。每次重启浏览器后解锁一次即可使用模型。

        

        
      

    

    

      
密钥保险箱

      

      
解锁后的密钥仅放在浏览器会话内存中；不会写入网页、日志或同步存储。加密保护磁盘中的密钥，无法防御已控制浏览器或操作系统的程序。
