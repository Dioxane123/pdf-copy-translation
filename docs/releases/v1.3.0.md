# PDF 复制助手 v1.3.0

- **网页段落**。鼠标停在原文上，单按 Shift 可在下方查看译文，再按一次收起。
- **YouTube 双语字幕**。在「翻译设置」开启自动翻译后，即使视频暂停也会预译首批字幕。每次约处理 45 秒，播放时按时间戳显示原文和译文，拖动进度条后优先翻译新位置。
- **字幕状态**。播放器会显示预译进度和服务错误，可直接重试。支持人工字幕、自动字幕和页面提供的文字稿。
- PDF、网页和字幕使用同一套谷歌翻译或模型配置、目标语言及密钥保险箱。YouTube 自动翻译默认关闭，可单独开启。

更新时将解压后的文件覆盖原扩展目录，在 Chrome 或 Edge 的扩展管理页重新加载，再刷新已经打开的网页和 PDF 标签页。
