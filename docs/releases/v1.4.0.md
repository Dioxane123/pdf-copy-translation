# PDF 复制助手 v1.4.0

- 修复 YouTube 评论区的 Shift 翻译。可翻译单条评论和回复，译文显示在折叠区域外。
- YouTube 原生 **CC** 按钮和 **C** 快捷键控制全部字幕。右侧控制栏最左边新增 **文A** 按钮，用于在双语字幕和原生字幕之间切换。新安装默认启用翻译，已有开关设置会保留。
- 原文和译文使用同一字幕框、字体与颜色。关闭任一开关会停止在途的预译，重新开启时从当前进度续译，已完成的译文可在当前视频中复用。

下载附件 `pdf-copy-cleaner-1.4.0.zip`。更新时用解压出的目录替换原安装目录，保持原路径，在扩展管理页点击「重新加载」并刷新 YouTube 页面。
