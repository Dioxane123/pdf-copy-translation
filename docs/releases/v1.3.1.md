# PDF 复制助手 v1.3.1

扩展源码按功能归入 `src/`，说明与截图归入 `docs/`，打包工具归入 `scripts/`。根目录的 `manifest.json` 仍可直接加载，已有 PDF 阅读模式链接继续有效。

本版包含 PDF 复制换行处理与翻译浮窗、Shift 网页段落翻译和 YouTube 双语字幕预译。自本版起，新版本进入 `main` 并通过测试后会自动发布为 GitHub Release，附件包含安装 ZIP 和 SHA-256 校验文件。

**安装或更新**　下载附件 `pdf-copy-cleaner-1.3.1.zip`。首次安装时在扩展管理页选择「加载已解压的扩展程序」，选择解压出的 `pdf-copy-cleaner` 目录。更新时用新目录整体替换旧目录，保持原安装路径，点击「重新加载」并刷新已打开的网页及 PDF 标签页。现有设置与加密密钥会保留。
