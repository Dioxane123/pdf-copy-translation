PDF 复制助手的首个 GitHub Release，适用于桌面 Chrome / Edge。

## 功能

- 复制 PDF 文字时，将每个换行替换为空格，保留原有空格。
- 扩展 PDF 阅读模式支持复制翻译浮窗：取消选区后关闭，点击或选中译文可保留。
- 支持谷歌翻译及自定义 Chat Completions 兼容模型。
- GPT / DeepSeek 参数模板支持推理设置，同时保留自定义 Base URL 和模型名。
- API_KEY 使用口令加密保存，解锁后仅保留在浏览器会话内存。
- 禁用可选 WebGPU 渲染，解决部分环境的 `No available adapters.` 提示。

## 安装

1. 下载下方附件 **pdf-copy-cleaner-1.2.1.zip** 并解压到固定目录。
2. 打开 `chrome://extensions/` 或 `edge://extensions/`，开启开发者模式。
3. 点击「加载已解压的扩展程序」，选择包含 `manifest.json` 的 `pdf-copy-cleaner` 文件夹。
4. 在扩展面板打开「翻译设置」，配置并启用翻译；随后从 PDF 标签页选择「用翻译阅读模式打开」。

从旧版更新时，覆盖原扩展目录并点击「重新加载」，再刷新 PDF 页面。附件中的 `.sha256` 文件可用于检查 ZIP 完整性。GitHub 自动提供的 Source code 压缩包用于查看源码；安装请使用上方命名的 ZIP 附件。

## 说明

- 翻译浮窗需要扩展阅读模式；浏览器内置阅读器继续支持复制换行处理。
- 开启翻译后，仅将所选文字发送给用户选择的翻译服务，PDF 不会整份上传。
- 谷歌免密钥接口可能限流或不可用；自定义模型的费用和参数支持取决于服务商。
- 已在 Chrome for Testing 156 / Linux 验证；Edge 尚未实机验证。
- PDF.js 6.4.299 已本地打包，许可证与来源见 `THIRD_PARTY_NOTICES.md`。
